# 隐藏成本检查清单

## 初始投入

- [ ] 设备、安装、装修、运输与调试
- [ ] 研发、设计、软件和数据迁移
- [ ] 许可证、押金、保证金和专业服务
- [ ] 初始库存、招聘、培训与开业营销

## 持续运营

- [ ] 工资、社保、福利、创始人无薪时间
- [ ] 租金、水电、云服务、订阅和通信
- [ ] 获客成本、渠道佣金、退款与售后
- [ ] 维修、停机、损耗、保险和合规审计
- [ ] 税费、支付费率、坏账和价格折扣

## 资金占用

- [ ] 应收账款账期
- [ ] 库存和在途库存
- [ ] 预付款与最低现金储备
- [ ] 供应商账期变化

## 风险、机会与退出

- [ ] 延期、返工、停机和关键人员离职
- [ ] 汇率、通胀和原材料价格变化
- [ ] 自有场地、设备、资金与时间的机会成本
- [ ] 对现有产品的蚕食效应
- [ ] 合同解除、关闭、清理和人员补偿
- [ ] 残值、押金与营运资金回收

## 防止重复计算

- 沉没成本不进入继续投资现金流。
- 预备金只覆盖尚未在具体成本中计入的剩余风险。
- 项目整体现金流采用 WACC 时不重复扣利息。
- 含通胀现金流不能再用实际折现率。
