# 金融与商业判断框架

## 一、先定义决策

- 决策问题是什么？是启动、继续、扩张、收购还是退出？
- 不做项目时，资金、时间、设备和场地还能用于什么？
- 有哪些规模更小、风险更低或可延后的替代方案？
- 决策者是经营者、债权人、股权投资者还是合作方？不同视角的现金流不能混算。

## 二、商业判断

收入不是输入框中的一个数字，而是一组待验证的因果假设：

`目标客群 → 可触达人数 → 转化率 → 客户数 → 客单价 → 购买频次 → 留存/复购 → 收入`

至少考察需求证据、市场容量、竞争者、替代品、价格接受度、渠道成本、交付能力和进入壁垒。关键假设分成：

- 已知：合同、历史账单、正式报价等直接证据。
- 估算：类比数据、访谈或小样本测试。
- 待验证：尚无证据，不应被伪装成精确数字。

## 三、财务判断

- 只纳入因该决策而发生变化的增量现金流。
- 沉没成本已经不可改变，应单独展示但不影响继续/停止决策。
- 自有资源也有机会成本，应按下一最佳用途的价值计入。
- 名义现金流配名义折现率；实际现金流配实际折现率。
- 项目整体现金流使用资金成本折现时，不应再次扣除利息。
- 互斥项目规模不同时，优先比较 NPV；资本受限时再参考利润指数和 IRR。

## 四、结论强度

- **建议推进**：基准和悲观情景均创造价值，关键证据充分。
- **满足条件后推进**：基准为正，但悲观情景或隐藏成本仍有风险。
- **继续验证**：价值可能为正，但关键假设证据不足。
- **暂缓**：基准为负，只有乐观情景可行。
- **拒绝**：连乐观情景也无法覆盖资金成本。
