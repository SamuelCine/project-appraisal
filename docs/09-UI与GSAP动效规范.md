# UI 与 GSAP 动效规范

## 视觉方向

- 暖白纸张背景、深墨正文、单一铜金强调色。
- 数字使用等宽或表格数字，帮助比较金额和比率。
- 使用细边框、克制阴影和较小圆角，避免股票终端或通用卡片墙。
- 市场数据只放在“假设依据”抽屉中。

## 信息架构

- 首次进入：六阶段引导式考察。
- 工作台左栏：事实、证据、假设和隐藏成本。
- 中栏：经营驱动、现金流和反向投资。
- 右栏：结论、指标、情景、临界值和审计解释。
- 小屏幕依次堆叠三栏，不隐藏关键结论。

## 动效

- 页面进入：标题和区域以 200–500ms 轻微位移与透明度出现。
- 参数变化：结果区使用轻微 `scale` 与 `autoAlpha` 表示重新计算。
- 只动画 transform、opacity 和 SVG 属性，避免动画 width/height/top/left。
- 使用 GSAP timeline 和 matchMedia；组件卸载必须 revert/kill。
- `prefers-reduced-motion` 下禁用非必要动画。
- 禁止行情跑马灯、持续背景动画和无意义数字滚动。
