# 反向投资与 IRR 说明

## 三个不同的金额

### 最低可行投入

`必要启动成本 + 最低运营规模成本 + 营运资金 + 风险预备金`

这是项目能否真实启动并维持的运营下限，不是 IRR 自动算出来的数字。

### 投资价值上限

`价值上限 = Σ 未来自由现金流ₜ / (1 + 最低可接受回报率)ᵗ`

超过这个价格，即使预测实现，也无法达到最低回报要求。

### 谈判报价区间

- 上限：以最低可接受回报率折现。
- 下限：以更高的目标回报率折现。
- 若购买部分权益，再乘以权益比例，并扣除未来追加资金、债务和优先权影响。

## 三年后获得 100 万元

假设中间没有其他现金流，最低回报要求为 10%：

`今天的价值上限 = 1,000,000 / 1.1³ ≈ 751,315 元`

若希望达到 20% 回报：

`谈判下限参考 = 1,000,000 / 1.2³ ≈ 578,704 元`

若最低可行投入为 600,000 元，则安全边际约 151,315 元；如果最低可行投入高于 751,315 元，当前方案在这些假设下不可行。

## IRR 注意事项

- IRR 必须和资金成本或最低回报要求比较，不能单独判断好坏。
- 现金流多次正负切换时可能有多个 IRR 或没有有效解。
- 规模不同的互斥项目可能出现 NPV 与 IRR 排序冲突，此时优先 NPV。
