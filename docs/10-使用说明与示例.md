# 使用说明与示例

## 1. 安装与启动

### 从 GitHub 获取

```bash
git clone https://github.com/SamuelCine/project-appraisal.git
cd project-appraisal
git switch codex/project-appraisal
npm install
npm run dev
```

也可以直接使用本机工作目录：

```bash
cd "/Users/samuel/Documents/ChatGPT/项目规划测试"
npm install
npm run dev
```

浏览器打开 `http://localhost:3000`。推荐使用 Node.js 20 或更高版本。

生产环境本地运行：

```bash
npm run build
npm start
```

## 2. 可选配置

免费汇率无需 Key。FRED 和 Trading Economics 为可选数据源：

```bash
FRED_API_KEY=你的_FRED_Key
TRADING_ECONOMICS_API_KEY=你的_TE_Key
PROJECT_DB_PATH=/绝对路径/project-appraisal.db
```

不要把真实 Key 写入 Git、Obsidian 或截图。系统不使用 OpenAI API Key。

## 3. 六阶段项目考察

1. **定义决策**：填写项目目标、周期、币种、行业、你的角色、“不做项目”基准方案和可比较替代方案。
2. **商业验证**：记录目标客户、需求证据、市场容量、竞争者、替代品、价格接受度和进入壁垒。
3. **隐藏成本**：检查初始投入、持续成本、创始人时间、营运资金、风险成本、机会成本、退出成本和残值。
4. **收益驱动**：用客户数、转化率、客单价、购买频次和变动成本率建立收入，而不是直接填写一个乐观总收入。
5. **财务参数**：设置最低可接受回报率、目标回报率和真实现金流；名义现金流与名义折现率、实际现金流与实际折现率必须匹配。
6. **风险决策**：查看悲观、基准、乐观情景，识别敏感变量、NPV 临界值和失败条件。

每项关键输入应标记为“已知、估算、待验证”，并尽量填写来源、观察日期和可信度。缺少证据时，应建立验证任务，不要让系统或个人凭感觉补全。

## 4. 如何阅读结果

- **NPV 大于 0**：按当前现金流与折现率假设，项目创造价值；仍需检查假设质量和执行风险。
- **IRR 高于最低回报要求**：项目内部回报率达到门槛。现金流多次变号时，IRR 可能有多个解，应以 NPV/MIRR 为主。
- **最低可行投入**：让项目能够启动并存活所需的最低资金，不代表项目值这么多。
- **谈判下限**：使用较高目标回报率折现得到的报价参考。
- **投资价值上限**：使用最低可接受回报率折现未来自由现金流所得的最高合理投入。
- **安全边际**：价值上限减去最低可行投入。小于 0 时，当前方案在设定条件下不可行。
- **临界值**：价格、销量、成本或延期达到何种程度会令 NPV 变为 0。

## 5. 反向投资计算

当你知道未来目标收益、实现时间和目标回报率时：

1. 打开中栏的反向投资计算器。
2. 输入未来净现金流目标，例如三年后获得 100 万元。
3. 输入最低可接受回报率和更高的目标回报率。
4. 输入项目最低可行投入。
5. 比较谈判下限、投资价值上限和安全边际。

反向估值回答的是“未来现金流在今天最多值多少钱”，不能证明未来现金流一定能够实现。

## 6. 市场数据

- USD/CNY 等免费参考汇率默认使用 Frankfurter，失败时回退 ECB。
- FRED 用于美国利率、通胀等宏观假设，需要用户自己的 Key。
- Trading Economics 为可选订阅数据源。
- 市场数据只用于支持汇率、通胀、折现率和成本假设，不用于股票交易判断。
- 参考汇率不是银行或交易所的成交价。数据过期、失败或单位不一致时应手工复核，并记录覆盖原因。

## 7. 保存与导出

- 项目保存到本地 SQLite，默认文件为项目目录下的 `project-appraisal.db`。
- 可通过 `PROJECT_DB_PATH` 指定数据库位置。
- 支持 JSON、CSV 和 Markdown 决策报告导出。
- Markdown 报告包含问题、框架、输入状态、现金流、公式、来源、情景、敏感性、反面证据、结论和验证任务。

## 8. 示例

三年后获得 100 万元，最低回报要求 10%，目标回报 20%，最低可行投入 60 万元：

- 投资价值上限约 75.13 万元。
- 谈判下限参考约 57.87 万元。
- 最低可行投入为 60 万元。
- 安全边际约 15.13 万元。

这不代表项目一定成功；还必须验证“三年后确实能产生 100 万元净现金流”这一核心假设。
