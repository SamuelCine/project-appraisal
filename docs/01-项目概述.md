# 衡策：项目考察与反向投资决策系统

## 要解决的问题

衡策不是股票行情工具，而是帮助普通人评估一个真实项目：实际要投入多少、未来可能回收多少、今天最多值得投多少，以及哪些遗漏会令结论失效。

## 核心原则

1. 先验证需求和商业逻辑，再预测收入。
2. 使用增量现金流，不把沉没成本混入继续投资决策。
3. 以 NPV 判断创造的价值，以 IRR/MIRR、回收期和盈亏平衡作辅助。
4. 所有估算标注来源、观察日期与可信度。
5. 每次预测同时给出悲观、基准、乐观情景、敏感变量和临界值。
6. 输出可审计的解释，不输出无法验证的“神秘结论”。
