# 风险、敏感性与临界值

## 三情景

- 悲观：收入下降、成本上升、折现率上升。
- 基准：当前最可信的估算。
- 乐观：收入提高、成本下降，但不能用来掩盖基准不可行。

情景不是概率预测，而是检查结论在成组假设下是否稳定。

## 单因素敏感性

依次改变价格、销量、成本、进度、汇率和折现率，其他条件保持不变。将每个变量造成的 NPV 变化跨度排序，可找出最值得验证和管理的变量。

## 临界值

临界值回答的不是“结果会变多少”，而是“变量变到什么程度，结论会翻转”。例如：

- 收入降到基准的多少比例，NPV 会变成零？
- 成本最多能上涨多少？
- 项目最多能延期多久？
- 折现率升到多少时不再创造价值？该点通常接近 IRR。

## 乐观偏差

项目常系统性低估成本和工期、高估收益。优先使用自己或同类项目的历史预测误差调整；没有历史数据时，预备金必须明确列出且进行敏感性测试，不能成为随意填入的“安全数字”。
