# 汇率与市场数据

## 数据如何进入判断

市场数据只用于支持以下假设：

- 多币种收入和成本的换算。
- 名义折现率、通胀和风险溢价。
- 用户主动选择的原材料或商品价格。

股票和加密货币行情不进入第一版项目判断。

## 数据源

- Frankfurter：默认免费汇率，来自央行参考数据，无需 Key。
- ECB：Frankfurter 失败时的欧元参考汇率回退源。
- FRED：美国利率、通胀等宏观时间序列，需要 FRED Key。
- Trading Economics：可选的全球宏观、商品和更高频数据，需要独立订阅 Key。

## 统一快照字段

每个市场快照必须保留：键、数值、来源、观察时间、抓取时间、单位、币种、频率和是否过期。

参考汇率不是交易报价。数据接口失败、过期或单位不一致时，系统应提示并允许手工覆盖；手工覆盖必须写明来源、日期和理由。

## 环境变量

免费汇率无需配置。可选数据源使用：

```text
FRED_API_KEY=
TRADING_ECONOMICS_API_KEY=
```

不要把真实 Key 写进 Git 或 Obsidian。
