# 收益预测与现金流模型

## 经营驱动

通用服务模型：

`收入 = 潜在客户数 × 转化率 × 客单价 × 购买频次`

产品模型：

`贡献毛利 = 销量 ×（单价 − 单位变动成本）`

订阅模型还应加入新增客户、流失率、ARPU、CAC 和服务成本。已有可靠预算时，可直接输入逐月或逐年现金流覆盖驱动模型。

## 自由现金流

`自由现金流 = 收入 − 现金运营成本 − 税费 − 资本开支 − 营运资金增加 + 税后残值`

营运资金通常在项目开始时形成现金流出，在结束时回收。折旧本身不是现金支出，但在适用税制下可能形成税盾；税务参数需由用户或专业人士确认。

## 指标

- `NPV = Σ CFₜ / (1+r)ᵗ`
- IRR：使 NPV 等于零的折现率。
- MIRR：按资金成本融资并按再投资率复投，避免 IRR 的再投资假设和多解问题。
- ROI：项目净收益相对投入的比例，不反映现金流时间。
- 利润指数：折现流入 / 折现流出。
- 回收期：累计现金流转正的时间；折现回收期先对每期现金流折现。
- 盈亏平衡销量：`固定成本 /（售价 − 单位变动成本）`。
